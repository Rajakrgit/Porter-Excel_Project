# Porter-Excel_Project
# 1. Project Overview

The Porter Delivery Analytics project analyses food-delivery order data
to understand delivery-time performance and identify operational factors
that may contribute to delays.

The project brief describes a delivery business experiencing rising
delivery times and increased competition. The analysis is intended to
help operations, marketing, customer service, and logistics stakeholders
understand order demand, peak periods, store-category performance, and
delivery-partner availability.

# 2. Business Requirements
• Calculate average and median delivery time.

• Analyse daily and hourly order volumes.

• Identify slow-performing store categories.

• Compare delivery performance across markets.

• Study delivery-partner availability.

• Identify orders delivered within 30 minutes.

# 3. Tools & Technologies
Tool: Microsoft Excel.

Techniques: Data cleaning, timestamp conversion, Pivot Tables, Pivot Charts, slicers, correlation and IQR outlier analysis.

Calculated fields: Delivery_time_minutes, Within 30 min, Created_hour and Day_of_Week.

# 4. Challenges Faced
• Handling missing values.

• Converting timestamp strings into datetime format.

• Calculating delivery duration accurately.

• Identifying extreme delivery-time outliers.

• Analysing categories with different order volumes.

• Presenting multiple metrics in one dashboard.

# 5. Key Dashboard Insights
• Sunday has the highest average delivery time: 51.25 minutes.

• Wednesday has the lowest average delivery time: 43.24 minutes.

• Saturday has the highest order volume: 34,541.

• Italian is the slowest displayed category: 68.25 minutes.

• Only 14.9% of orders are delivered within 30 minutes.

• Market 2 has the highest order volume in the supporting analysis.

# 6. Recommendations
• Increase delivery-partner capacity during weekend peaks.

• Investigate delays in Italian store deliveries.

• Improve the percentage of orders delivered within 30 minutes.

• Optimise partner allocation during peak hours.

• Compare market-wise delivery performance.

• Investigate unusually delayed orders.
